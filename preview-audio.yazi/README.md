# Installation

```sh
ya pkg add AminurAlam/yazi-plugins:preview-audio
```

# Dependencies

- [exiftool](https://repology.org/project/exiftool/versions) - for extracting metadata

# Usage

in `~/.config/yazi/init.lua`

```lua
require('preview-audio'):setup()
```
